# DocuRAG:  📚 RAG Q&A System

A Streamlit-based Retrieval-Augmented Generation app that allows users to upload documents and ask questions.

## 🚀 Features
- Supports PDF, DOCX, TXT, Links
- Uses FAISS for vector storage
- HuggingFace LLM for answering

## 🛠 Tech Stack
- Streamlit
- LangChain
- FAISS
- HuggingFace

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
